# Min-Max Log

A phone workout logger for a 12-week, 4-day training program. Install it from Safari with **Share → Add to Home Screen**.

- Works offline once installed.
- Your program and workouts are stored only on your phone (browser storage). Nothing is uploaded.
- The app ships with no program content. On first launch you load your own copy of the program's tracker spreadsheet, and it is read on the device.
- Back up from **Guide → Your data → Export backup**.

Spreadsheet reading uses [SheetJS](https://sheetjs.com) (Apache-2.0), included in `vendor/`.
